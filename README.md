# BioCode Lab - Python ile Biyoinformatik ve Doku Mühendisliği Eğitimi

BioCode Lab, biyoinformatik, doku mühendisliği, biyoistatistik ve hücre biyolojisi alanlarında Python kullanarak problem çözmeyi öğreten interaktif ve tek sayfalık (single-page) bir kodlama laboratuvarıdır.

## 🌟 Özellikler
- **Kapsamlı Konu Başlıkları**: Genomik & DNA (10), Protein Analizi (9), Doku Mühendisliği (10), Biyoistatistik (9) ve Hücre Biyolojisi (7) alanlarında toplam 45 özel problem.
- **Dahili Python IDE**: Web tarayıcısı üzerinden Python kodları yazıp çalıştırabileceğiniz entegre geliştirme ortamı.
- **İpuçları ve Konu Anlatımları**: Her problem için kademeli ipuçları ve detaylı konu anlatımı/çözüm yaklaşımı içeren zengin kaynaklar.
- **Serbest IDE**: Belirli problemlere bağlı kalmadan serbestçe Python kodu yazıp test edebileceğiniz bağımsız kodlama alanı.
- **Kişisel Notlar**: Başarılı çözümler sonrasında oluşturulan veya kaydedilen çalışma notları alanı.

## 🚀 Çalıştırma Yöntemi
Proje, tüm HTML, CSS ve JavaScript mantığını tek bir dosyada barındıracak şekilde tasarlanmıştır.

1. Projeyi bilgisayarınıza indirin veya klonlayın.
2. Klasör içindeki **`index.html`** (orijinal adıyla `biocode-lab.html`) dosyasına çift tıklayarak tarayıcınızda doğrudan açıp kullanmaya başlayabilirsiniz. Herhangi bir sunucu kurulumu veya ekstra bağımlılık gerektirmez.
